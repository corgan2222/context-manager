# AI Policy

## How I use AI

I use AI tools when I write code for this project: drafting, refactoring, writing
tests, working through documentation. I read everything they produce before it
lands.

Nothing gets committed that I have not reviewed and understood. If you find a bug
in here, it is mine, not a tool's. I do not ship code I cannot explain.

The same goes for releases. Version bumps, changelogs, and anything published
under my name went past my eyes first.

## If you want to contribute

Use whatever tools help you. What I care about is the result, and whether you
understand it.

Before you open a pull request, make sure you can explain every change in it. Not
the summary, the actual diff. If I ask a question and you cannot answer it without
going back to a chatbot, the pull request is not ready.

I review contributions in my free time. A pull request I have to reverse-engineer
costs me more than writing the feature myself, and I will close it rather than
spend an evening on it.

## No autonomous agents

Do not point an agent at this repository and let it file issues or pull requests
on its own. I close those without reading them.

Same for bug reports. An AI-written report describing a plausible-sounding problem
the code does not have wastes my time and yours. Run the code, hit the bug, then
tell me what happened, what you expected, and what your setup looks like.

## Comments and discussion

Write your own comments. Using AI to fix grammar or tighten a paragraph is fine.
Pasting an unreviewed wall of generated text is not, and I will hide it.

If you want to include something an AI told you, a stack trace analysis or a
suggested fix, mark it as such in a quote block and add your own read on it. Keep
it short. Your reasoning is what I am after; the model output is context for it.

## Language

German or English both work. I am a German speaker, and I would rather read your
clear German than your machine-translated English.

If you do translate, put the original in a `<details>` block so I can check it
when the meaning is unclear.

## Reality check

I maintain this alone, alongside a full-time job. Response times vary. If your
pull request follows this policy and you have not heard from me in two weeks,
ping me. If it does not, I will say so and close it.

None of this is meant to talk you out of using AI. It is meant to keep the code in
this repository something a human has actually looked at, because it runs in other
people's homes.
